Odoo 17 Document Linkage with Sale Order

This Odoo module customizes the Documents module by linking it with Sale Orders and adding a document count button in the Sale Order view.

KEY HIGHLIGHTS

Sale Field In Document

Seamlessly link the documents to Sale Orders with the new custom_sale_order_id field in the Documents module!

Document Count In Sale Order

Automatically calculates and shows the count of related documents on Sale Orders!

Find In Search View

Easily we can find Sale Orders by searching for the order reference in the search view!

Connect The Module Effortlessly

Link Documents To Sale Orders

Open the Documents module from the dashboard -> Select any document from the list -> In the document details you will see a fields i.e Sale.

Instantly tally up your related documents on Sale Orders

Automatically calculates and shows the count of related documents on Sale Orders!

Navigate to the Sale Order -> There is now a button that allows you to directly view the associated documents.

Find Sale Orders in a snap

We can search the required Sale Order in search view by searching order reference.

Easily find the desired Sale Order in the search view -> Simply enter the order reference to search.

Installation Instructions

  1. Download the Module
    • Download the Allow SO Linkage on Documents App Store.
    • Save the downloaded module file (usually a .zip file) to your Odoo addons.
    • Log in to your Odoo system as an Administrator.
    • Navigate to the Apps module on your Odoo dashboard.
  2. Install the Module
    • Once the module is uploaded, it will appear in the Apps list.
    • Click the Install button next to the Allow SO Linkage On Documents.
    • Odoo will install the module for you. Once it's done, the module is ready to use!
  3. Troubleshooting
    • If you don't see the module in the Apps list: Ensure that you have activated developer mode by going to Settings→Activate Developer Mode.
