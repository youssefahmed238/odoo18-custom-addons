Overview :
----------
This module extends the Odoo Documents module by adding custom fields to link Sale Order with documents. It enhances the functionality by displaying related sale for each document, as well as providing a document count on Sale Order record.


Features :
----------
    • Sale FIelds in Documents : Add `custom_sale_order_id`  fields to the Documents module, allowing users to associate a document with a Sale Order.
    • Document Count : Automatically computes and displays the number of related documents on Sale Orders
    • View Related Documents : Adds a button on Sale to view the related documents in a kanban view.
    • Search View : We can search the required Sale Order in search view by searching order reference.

Installation Process :
----------------------
Follow these steps to install and use the Document Customization module for Sale Orders in Odoo.
Steps :
    a. Download the Module
        1. Download the Allow SO Linkage On Documents module from the Odoo App Store.
        2. Save the downloaded module file (usually a .zip file) to your odoo addons.
        3. Log in to your Odoo system as an Administrator.
        4. Navigate to the Apps module on your Odoo dashboard.
    b. Install the Module
        1. Once the module is uploaded, you will see it appear in the Apps list.
        2. Click the Install button next to the Allow SO Linkage On Documents module.
        3. Odoo will install the module for you. Once it's done, the module is ready to use!
    c. Troubleshooting
        1. If you don’t see the module in the Apps list : Ensure that you have activated the developer mode by going to settings -> Activate Developer Mode.
